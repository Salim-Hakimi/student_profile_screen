# Student Profile Screen – Flutter Mini Project

A single-screen Flutter student profile app built for the Advanced Mobile Programming mini project.

## Features
- SafeArea and scrollable content
- Profile header and reusable information cards
- Text, RichText, Row, Column, and nested layouts
- Responsive spacing and alignment
- Long text handled with maxLines and TextOverflow.ellipsis
- const widgets wherever appropriate

## Run
```bash
flutter pub get
flutter run
```

Replace the sample student details in `lib/main.dart` with your own information if required.
